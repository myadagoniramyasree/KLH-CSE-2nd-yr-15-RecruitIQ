# RecruitIQ

## Project Title
BERT vs GPT vs T5 Model Selection for HR Automation

## Project Description
RecruitIQ is an AI-powered HR application that compares BERT, GPT, and T5 models for recruitment-related tasks. It helps evaluate different models based on their performance and suitability for HR automation.

## Objectives
- Compare BERT, GPT, and T5 models.
- Explore AI applications in recruitment.
- Evaluate model performance.
- Identify the most suitable model for different HR tasks.

## Project Structure
- `src/` – Source code
- `docs/` – Project documentation
- `data/` – Datasets
- `results/` – Model outputs and evaluation results
- `reports/` – Project reports

## Technologies
- Python
- BERT
- GPT
- T5
- Natural Language Processing
